# Moon contrast source candidate

`authoring.blend` is the complete separate floor/ceiling/moon candidate. It is
not installed as canonical source. `moon-atlas.json` pairs the original packed
painting with explicit 45% base/emission luminance intent. The PNG bytes remain
in `../../../textures/backdrops/moon-paint/moon-paint.png`; the native source
also packs the original image.

Source checks and actual exported/imported evidence are documented in
`../../../docs/moon-contrast.md`. Fresh whole-source lighting and final visual
acceptance are pending. Opening this file does not require saving or reloading
the user's existing Blender scene.
