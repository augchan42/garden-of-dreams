# Tech atlas

Original deterministic 2048 × 2048 RGB textures generated by `scripts/make_tech_atlas.py`: warm case paint, timber grain, steel, bronze, cables, keyboard and amber/green CRT dressing. The atlas layout is in `atlas.json`; base color, ORM and emission are packed into Blender and embedded in each module GLB.

CRT text is typeset with the system Menlo Bold font. No font file is redistributed. Larger glyphs retain their shape in the compressed 512px runtime emission import. Dark scanlines are baked into RGB; the screens remain opaque. This artwork is static dressing and does not represent live service data.

Godot shares a single ORM material and imports compressed mipmapped color/emission maps at 512px and ORM at 256px. Emission strength is four. The source maps remain 2048px. There are no realtime light objects in the kit.
