# Entrance water stains

`gate-water-drips.png` is an original 512 × 512 RGBA texture generated by `scripts/generate_gate_drip.py`, using seed 2319. It contains nineteen irregular mineral/water streaks with transparent margins. No external images are used.

`scripts/dress_rockery_gate.py` projects its mesh onto the actual second-bend rock surface, offset 12 mm into the passage to avoid coplanar flicker. The image is embedded in the Blender site and glTF export. Final lighting and bake acceptance remain separate.
