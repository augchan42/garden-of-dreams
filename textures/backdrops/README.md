# Painted backdrop assets

`daoxiang-paddy-v1.png` is an AI-generated gouache-style rice-paddy painting created for this project with the built-in image-generation tool. It is an original production texture, not a sourced film or architectural reference and does not satisfy the site’s three-reference requirement.

Native size: 1774 × 887. The original generated image is preserved here without resizing or recolouring. Blender packs it into the farmhouse library and the exporter embeds it in the GLB. The main painted flat is 6 × 3 m with explicit UV0 coordinates; UV2 is allocated separately for lighting.

Art direction: dark jade/olive and muted ochre, rice terraces over the lower two-thirds, low hills above, visible gouache strokes and canvas texture, no text or buildings. The Godot scene applies its normal green lighting and global grade.
