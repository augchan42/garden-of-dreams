# Painted mountain flats

Original deterministic raster art from `scripts/make_mountain_paint.py`, seed 7419. No external images. Three slate-blue pigment bands share one 4096 × 4096 PNG. Short strokes and broad pigment variation make the physical flats visibly painted. This production artwork does not count as an external site reference.

`atlas.json` records linear palettes, decoded mean colors, padded UV regions and the PNG hash. Blender links the same image to base color and emission at the existing 0.6 strength. Average emitted luminance stays within 10% of the preceding flat colors; the original green emission is replaced along with the base color. Mesh silhouettes, transforms, lighting rig and studio arrangement are preserved.

Runtime resolution, material transfer, fresh bakes, memory and rendered acceptance must be verified separately before installation. The source image remains 4096px.
