# Baked lighting transfer

The garden uses Godot Compatibility rendering. Cycles diffuse bakes include Lambert's `1/π`; Compatibility's unit-light diffuse response does not. The bake shader multiplies only the baked diffuse term by π. Material emission keeps its original energy.

The independent white-plane fixture is generated by `scripts/bake_transfer_fixture.py`. Blender 5.2.2 Cycles reports a native linear mean of 0.318303 under unit white sunlight. On a gray plane, Godot 4.7.2 reports display RGB 0.501961 with dynamic sunlight. The old bake shader reports 0.152941; the corrected shader reports 0.498039. `test_bake_transfer.gd` compares all three channels through the actual imported fixture and production shader, with a 0.01 display tolerance. This is a Compatibility transfer check, not a claim about other renderers.

Baked meshes use layer 2. Static Spot/Directional keys use receiver layer 1 only. Merely clearing layer 2 is insufficient: reflected meshes and linked backdrop flats also carry camera/wash bits that would admit static light. Practical Omni lights use layers 1 and 2. The production backdrop wash is baked; the dynamic layer-4 substitute is retained only for unbaked diagnostics. Static shadow-caster masks stay unchanged so baked buildings can still shadow unbaked paths. `test_bake_adapter.gd` checks these contracts alongside source hashes and material properties. Normal exploration and the demo disable static shadow maps because eligible static receivers now have bake coverage. Mesh camera and wash layers remain intact.

The imperial comparison isolates the receiver mask and map resolution. Before the correction, the sampled door region averaged display RGB (0.0454, 0.0343, 0.0080) with isolated static receivers; after correction it averages (0.1389, 0.1031, 0.0397). The roof region changes from (0.0512, 0.0680, 0.0580) to (0.1060, 0.1381, 0.1067). Native-resolution maps improve detail but do not explain the transfer mismatch. `godot/imperial-bake-transfer-comparison.json` records the fixed rectangles and both measurements; `diagnose_imperial_bake.gd` reproduces overlap, isolation and native-map variants without saving runtime changes.

The source GLB and authored lights were unchanged by the earlier transfer correction. The later owned-key pass changed the lights and refreshed every ordinary map; the current catalog uses fresh bakes rather than that historical camera-only compatibility proof. Desktop and portrait arrival references are refreshed for all fourteen sites.

All 124 eligible meshes now have current source-matched maps in `godot/lightmaps/full-index.json`. The owned-key and neutral-fill pass freshly rendered all 124 maps at 128 Cycles samples, with source sizes up to 1024². No current record uses camera-only revalidation. The source coverage check requires every eligible mesh, validates native pixels, and confirms identical engine copies before installation. Runtime maps use compression, a 256-pixel limit and no mipmaps. Older source experiments remain outside the current catalog.

The adapter retains source normal maps and their strength. A rendered side-light fixture measures 0.439216 with normals, 0.301961 flat and 0.301961 at zero normal depth. Layer tests verify that baked flats retain their wash and reflection bits while static keys cannot reach them through those extra bits. The production pond reports 92 main plus 13 reflection draws, zero static shadow draws, 115,470 combined visible primitives and 63,142,466 texture bytes on Apple M2 Max at 1410 × 600. Its median active interval is 2.256 ms; frozen is 1.915 ms. These are stationary desktop measurements.

Final atlas/color review, bake noise and texel density, external references, full traversal and phone GPU acceptance remain open. The native Area-light wash is installed as described below. Its final color, filtering and moving-camera quality remain part of the art review.

The demo input helper forces each layout-check draw and requires stable button bounds, then restores the injected pointer position on both click edges. This avoids indefinite automatic-draw waits observed while physics continued. Project and pack full pointer/keyboard replay pass. The movie capture has an explicit native frame-sequence mode; `assemble_demo_capture.py` checks contiguous frames and mixes original cue PCM at recorded cue transitions with the runtime gains and loop/stop rules. It does not use audio from the shortened automatic movie attempts.

## Native backdrop wash

`scripts/author_site_washes.py` authors twelve exterior-site Area lights in `blender/authoring.blend`. Each is a 150 W, 15 × 10 m rectangle aimed at the painted enclosure along its site’s establishing camera sightline. Eleven use neutral gray-blue; Qinfang uses a faint neutral green. The old 1,800 W shared wash is retained with zero energy. Terminal cells borrow window spill and the rockery tunnel explicitly has no wash, following their detailed site sheets.

`scripts/package_site_washes.py` saves directly openable libraries and links each wash to the same five visible receiver object IDs from `SITE_stage.blend`; the linked master identity check passes for all twelve lights. `scripts/bake_backdrop_wash.py` reads their exact saved transforms, colors, energies and dimensions from authoring, checks canonical GLB receiver bounds, and bakes their combined direct diffuse contribution in Cycles. Other lights, the world and emissive CRT/lantern sources are disabled. No source file is changed during baking. The prior wash-only export was byte-identical to all canonical GLBs. Adding three keys and changing shared fill in the current pass changed the source hash and required fresh ordinary maps for the entire assembly. `export/site-key-export-preservation.json` proves unchanged binary geometry/images, materials, cameras and 33 unrelated punctual-light records.

The final bake uses 128 samples at 512². Four double-sided receivers have separate front/back maps; the sky has one front map, for nine textures in total. The three mountain cards have outward normals while the interior camera sees their back faces. Reversing faces in the temporary bake scene preserves the exact UV-to-vertex mapping; Godot selects the appropriate map with `FRONT_FACING`. See the [Godot spatial shader reference](https://docs.godotengine.org/en/stable/tutorials/shaders/shader_reference/spatial_shader.html). The outermost mountain layer receives zero wash because the nearer flats occlude it; its isolated inward-face control receives 0.168890 linear light. The middle layer is mostly shadowed, with a small 0.002963 peak at final sample quality. A real building control receives zero direct wash.

The source maps, metadata and controls live under `export/lightmaps/backdrop-wash/`. `sync_backdrop_wash.py` rejects changed GLB, authoring, saved-stage or twelve site-library hashes, incomplete receiver sets and changed PNG contents before copying any engine files. New stale-authoring and stale-site negative checks leave all 25 installed files unchanged; evidence is `export/site-wash-provenance-check.json`. The runtime requires twelve light records and matching per-map authoring/site provenance before changing materials. Runtime maps are compressed and capped at 256 pixels with `configure_lightmap_imports.py --index backdrop-wash-index.json --size-limit 256`.

Normal exploration and the demo add the wash to the ordinary static bake in linear space, retaining source albedo, textures, emission and the sky's unshaded base. Demo startup also installs the four ordinary stage maps needed by the painted flats. There is no production `BackdropWash` realtime light. The five receiver meshes retain camera/layer bits; static keys cannot reach them. Unbaked diagnostics retain the old isolated light.

`test_baked_backdrop_wash.gd` checks the actual scene for five installed wash receivers, no building receivers, compressed maps and no realtime wash. `test_backdrop_wash_sides.gd` renders an independent native fixture: front RGB 0.498, back 0.0; half ordinary plus half wash RGB 0.498. It also compares an unshaded StandardMaterial with the converted shader and rejects loss of the painted sky base. The material, full-lighting and first-reading startup checks remain required.

`scripts/audit_lighting_rig.py` reads the saved authoring scene without editing it. `export/lighting-rig-audit.json` records twelve owned exterior washes, the two explicit site-sheet exceptions and no missing required owned keys or washes. Qinfang has a 0.6-energy Sun at 35° southeast with a 0.5° source; Ouxiang and Ziling have hard Spots aimed at their tea table and reed overlook. The shared fill is neutral cool RGB (0.70, 0.74, 0.78), energy 1.4. Desktop and 390 × 844 portrait arrival views are refreshed for all fourteen sites.

The backdrop maps contain direct light only. The separate terminal indirect pass below now supplies the window spill. Final shadow dominance, palette/material review, mountain-card bake noise/filtering and full moving-camera/phone acceptance remain open. Native transfer checks do not prove final site lighting acceptance.


## Native terminal indirect spill

`bake_terminal_spill.py` reconstructs the same twelve saved linked Areas in a temporary canonical GLB scene. The black world, hidden other lights and disabled material emission isolate their indirect contribution. Controls rasterize actual top-floor UV triangles into each cell interior, normalize transformed normals, and block the real marker-derived window/door locations. All six window-only controls are positive; direct, sealed and wash-off controls are zero. Controls do not alter the delivered room geometry.

The seven independent maps use 2048 fixed Cycles samples, no adaptive sampling or path guiding, and 512² source PNGs. Adaptive sampling had left many faint paths unresolved. The PNG values divide by their native linear maxima; the runtime scale restores the original energy, including scales below one. `inspect_terminal_spill_pixels.py` checks finite native pixels and decoded maxima. No gain or extra realtime light is added.

`sync_terminal_spill.py` validates the complete catalog against GLB, authoring, stage, terminal and twelve exterior-library hashes, canonical UV records, controls and every PNG before copying. `verify_terminal_spill_install.py` exercises stale authoring, stale terminal, changed UV, changed final PNG and adaptive-sampling metadata; all five reject with 23 engine files unchanged. Runtime imports are compressed at 256 pixels without mipmaps.

`terminal_spill.gd` prepares all seven material copies before applying a separate additive shader sampler. Ordinary bakes, albedo, normal maps, emission and receiver masks remain intact. The direct backdrop wash still reaches only its five painted receivers. Normal/demo runtime checks pass; the rendered fixture fails when the spill term is disabled and passes with normalized values decoded at their physical scale. This verifies implementation and transfer, not final art or phone acceptance.
