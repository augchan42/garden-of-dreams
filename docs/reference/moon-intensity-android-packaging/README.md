# Android diagnostic packaging

The revised exporter filters unused KIT-prefixed previews while retaining shared props/tech atlases and runtime flora. The current-source APK is 91,542,782 bytes, down from 544,760,470 (453,217,688 bytes saved). Native import/export passes without engine diagnostics.

The payload verifier preserves all 177 file-backed texture imports from the actual normal-route inventory, the generated reflection viewport and every used flora LOD variant. Retained imported payloads, runtime scripts and JSON catalogs are byte-identical to the broad baseline APK. Signed metadata, UID cache and regenerated scene bundles change. A too-broad folder filter is rejected for removing six actually bound props/tech textures; its build and corrective evidence remain archived.

The filtered APK is local only, not installed or accepted on the phone. The previously verified broad current-source APK remains installed, and its sampling awaits unlock. Archive preservation is not fresh physical-device, final scene art, sustained-performance or release acceptance.
