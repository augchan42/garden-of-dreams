# Garden palette transfer preparation

The CPU contract reads actual GLB plain color factors, non-collision source surface counts and embedded architectural image hashes. The exact combined-color fixture passes; the actual preceding plain-material/paving export rejects its old atlas colors, and the actual installed source rejects its old plain factors. The executed checks and rejection logs are retained. No invented positive factors are passed into the checker.

The Godot script will check imported sRGB plain factors, active baked shader colors, roughness/metallic/emission behavior, atlas color/normal/ORM bindings and decoded color swatches in normal exploration and the demo. Negative flags change an active plain color or substitute an actual preceding atlas in memory. These native checks have not yet run; Python syntax checks do not validate GDScript.

The queued final atlas review retains the existing 37 phases and adds one source-palette contract plus four native palette phases, for 42 phases. Its dispatch waits for the existing atlas source/bake processes to exit successfully before starting native work. Live status is referenced by checkpoint.json. This preparation is not native palette acceptance, visual approval, production adoption, phone profiling or service completion.
