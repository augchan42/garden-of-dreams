# Cycles lightmap pipeline

Current normal exploration uses 124 source-matched static maps: 116 across fourteen site libraries and eight shared stage meshes. The separate native Area-light wash covers five painted backdrop receivers with nine front/back textures. The current GLB hash is recorded in each catalog. See [baked-lighting.md](baked-lighting.md) for transfer calibration, layer contracts and validation limits.

1. Export the authoring scene with `scripts/export_garden.py`. Every render mesh has UV2; each material batch has its own unit-square chart.
2. Run native Blender with `scripts/bake_lightmaps.py --site <slug> --samples 128 --size 1024`. Static keys, ambient and emissive geometry contribute; point practicals are excluded. The source GLB stays unchanged during the run. `bake_lightmaps.py --site all` renders the complete ordinary catalog in one native run; `refresh_remaining_lightmaps.py` is the earlier later-site-only batch. `refresh_full_lighting.py` runs all ordinary maps, the wash, native pixel inspection and full coverage checks sequentially; `export/full-lighting-refresh.json` records its finished phases and current-source engine installation.
3. Run `scripts/inspect_lightmap_pixels.py` in Blender, then `python3 scripts/verify_lightmaps.py --current --require-all`. This checks current coverage and native-precision image contents; it does not certify seams or noise.
4. Run `python3 scripts/sync_full_lightmaps.py`. It validates the complete current catalog before copying files and creating `godot/lightmaps/full-index.json`.
5. Bake the omitted Area wash separately: `Blender --background --threads 8 --python-exit-code 1 --python scripts/bake_backdrop_wash.py -- --samples 128 --size 512`. This reads the twelve saved authoring Area lights, checks canonical receiver bounds and UV mapping, excludes all other sources and verifies a zero-spill building control.
6. Run `python3 scripts/sync_backdrop_wash.py`. It verifies GLB, authoring, stage and twelve site-library provenance plus all nine PNG hashes before creating `backdrop-wash-index.json`.
7. Import in Godot once, configure each catalog with `scripts/configure_lightmap_imports.py --index <catalog> --size-limit 256`, then import again. The runtime cap and compression leave the source PNGs unchanged.
8. Run the material, bake transfer, full-scene lighting and backdrop tests. Capture desktop/portrait route views and profile actual exploration. Godot's shader multiplies the native Cycles diffuse term by π for Compatibility rendering, adds wash and ordinary maps in linear space, and retains source material emission and unshaded bases.

Production now uses these maps. Old experimental indexes, images and profiles remain in the repository as historical evidence; they do not describe current production coverage or memory use. The demo retains its 33-entry priority-1 catalog and also loads four ordinary stage maps plus the five-receiver wash.

To regenerate the native rig, load `blender/authoring.blend` and run `scripts/author_site_washes.py --apply`, then run `scripts/package_site_washes.py` before baking. Packaging restores directly openable scenes and common external receiver IDs in the linked master. A proposal-only run should pass `--report /tmp/garden-site-wash-proposal.json` to preserve the saved rig report. When changing keys, use `scripts/author_site_keys.py --apply` and verify the saved source with `scripts/verify_site_keys.py`, then export with `scripts/export_garden.py`. Retain old maps only when source identity is proved; changed lighting requires fresh bakes. The current catalog has no retained compatibility records.


After the direct wash, run native Blender with `scripts/bake_terminal_spill.py` (2048 fixed samples, 512²), then `scripts/inspect_terminal_spill_pixels.py`. Run `python3 scripts/sync_terminal_spill.py` and the installer rejection verifier before engine import. Configure `--index terminal-spill-index.json --size-limit 256` and import again. The full refresh orchestrator now includes this source pass and its pixel check. These additional maps preserve the 124-entry ordinary catalog. Run `test_terminal_spill.gd` in normal/demo modes and the rendered additive fixture before accepting a new rig.

Native PNGs, UVs and scales are unchanged. `test_mountain_lightmap_filtering.gd` compares the actual portrait view with same-resolution native images; source, import hashes, RED/GREEN and memory evidence are in `export/mountain-filtering-checks.json`.
